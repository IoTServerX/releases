IoTServer 1.3.1
Released October 19, 2026

Agentic industrial infrastructure for Windows: industrial connections, a unified
signal namespace, visual mapping, modeling, transformation, simulation and
AI-assisted engineering.

Changes since 1.3.0
-------------------
Canvas and Worksheet are two views of the same field assignments, with synchronized
selection and one Properties Save/Cancel workflow. The former separate Bindings
layer is removed. Input record grids support organizing signals into records,
dragging directly onto records/fields and retaining shared field names.

Nodes can be placed freely on the canvas. Moving an existing node saves its
position automatically, separately from unfinished configuration changes and
without a runtime Apply. Independent layout revisions protect concurrent edits.
New unsaved nodes remain part of their creation draft.

Connector dragging shows an immediate line preview. Long orthogonal connections
use separated parallel tracks where space permits. Connector selection highlights
the line without a bounding rectangle. Output field labels no longer look like
connector circles; Write outputs show explicit per-record destinations, such as
Motor01 -> Follower01.SpeedDemand.

Includes the complete source snapshot and driver/runtime work committed since
the previous release, plus mapper, explorer, property-editor and regression-test
updates. This release does not establish additional physical-hardware qualification
or complete vendor-driver parity.

Installation and upgrade
------------------------
Choose the Windows x64 setup executable or portable ZIP. Both Desktop and Windows
service installation modes use C:\Program Files\IoTServer. Service data uses
C:\ProgramData\IoTServer. The IS desktop shortcut opens http://localhost:5180;
Desktop mode starts through Start IoTServer in the Start Menu.

Back up your project and security stores. Stop the host before upgrading; closing
the browser does not stop it. Refresh browser tabs after replacing the host.
Configure and Save your project, then explicitly Apply and Start when ready.

Without a full license, the runtime has a four-hour process trial. After expiry,
restart iotserver.exe to begin another trial session. Administration > Licensing
shows the machine ID and accepts a full license key.

The application includes the host, ODBC helpers, MCP Desktop bridge, launch/setup
scripts and reviewed examples. MCP authoring Save does not Apply or Start the
runtime. The separate dependency-notices ZIP contains dependency licenses and
corresponding dependency sources. Verify assets using SHA256SUMS.txt; the release
provenance file records source, build and packaging identities.

Limitations
-----------
Windows executables are unsigned. Clean-VM installer/service-mode/reboot
qualification remains incomplete. Driver support is limited to documented subsets;
hardware qualification and protocol certification remain incomplete. Unimplemented
driver skeletons remain unavailable. See the maintained driver documentation for
individual capabilities and limits.
