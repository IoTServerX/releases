IoTServer 1.3.0
Released October 13, 2026

New in 1.3.0
  21 usable adapters, up from eight. Added core runtimes for Allen-Bradley
  1609 UPS, PLC-2 Server Ethernet, Micro800, Alstom Redundant Ethernet,
  Aromat Ethernet, BACnet/IP, Beckhoff TwinCAT, Bristol IP, Busware Ethernet,
  CODESYS V2, ControlLogix Server, Cutler-Hammer ELC and Dataforth isoLynx.
  Driver configuration is available in the channel/device tree.
  All 71 driver families now have separate Rust crates. The 50 unfinished
  families remain disabled; the catalog distinguishes them from usable drivers.
  Removed the Help header link/modal and simplified Configuration API text.
  Installer and portable payloads contain only the executable and Start/Stop
  PowerShell scripts; installation also creates the uninstaller. Documentation
  and dependency notices are separate release downloads.

Included
  Existing Allen-Bradley, Modbus, OPC UA Client, ControlLogix, Mitsubishi,
  Siemens, MQTT Client and Memory Based adapters remain available.
  OPC UA server exposes tags, quality and timestamps with certificate security.
  Six plugin areas: Advanced Tags, Alarms & Events, Profile Library, DataLogger,
  IoT Gateway and Local Historian. Profile Library stores scripts but does not
  execute them. Connection Sharing is planned.

New driver scope
  UPS: SNMP v1 scalar/table reads and opt-in writes.
  PLC-2 Server: inbound CSP unprotected reads/writes and local memory table.
  Micro800: symbolic CIP scalar/array access and fragmented transfers.
  Alstom: redundant Ethernet register access and failover.
  Aromat: MEWTOCOL Ethernet scalar access.
  BACnet/IP: unicast ReadProperty/WriteProperty and scalar COV subscriptions;
    automatic discovery and routed networks are pending.
  TwinCAT: scalar ADS/TCP symbol access; controller routes must exist already.
  Bristol: BSAP/IP scalar access; advanced discovery is pending.
  Busware: Ethernet register and bit access.
  CODESYS: direct ARTI V2 Level 4, symbol download and scalar access;
    V3, gateway connections and password login are not supported.
  ControlLogix Server: unconnected EtherNet/IP symbolic scalar/array table;
    connected Class 3 and cyclic I/O are not supported.
  ELC: PV28 Modbus TCP register/bit maps and numeric arrays.
  isoLynx: SLX100 ASCII TCP analog/digital reads and output writes.
  Drivers implement defined subsets, not complete vendor parity. Hardware
  qualification and protocol certification have not been performed. DNP remains
  disabled while its application services are unfinished. No serial or OPC DA.

Install and upgrade
  Run IoTServer-1.3.0-windows-x64-setup.exe, then open IoTServer from the Start
  Menu. Configure a project, Apply Project and Start Runtime. The runtime starts
  stopped. Closing the browser leaves the host running; use Stop IoTServer.
  Stop the installed host before upgrading. User data is kept separately under
  %LOCALAPPDATA%\IoTServer and is preserved on uninstall. Program files live at
  %LOCALAPPDATA%\Programs\IoTServer. Older installations may retain documentation
  from previous versions; fresh installations use the reduced payload.
  Portable: extract the ZIP and run Start-IoTServer.ps1 with Windows PowerShell.
  Default configuration address: http://127.0.0.1:5180/.

Downloads
  Windows x64 installer, portable ZIP, release notes and SHA256SUMS.txt.
  IoTServer-1.3.0-third-party-notices.zip contains dependency license texts,
  the dependency index and unmodified MPL dependency source archives.
  Application source remains private. Windows artifacts are unsigned.
