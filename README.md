# IoTServer

Industrial connectivity for Windows, with browser-based configuration and an OPC UA server.

## Download 1.3.0

- [Windows installer](https://github.com/IoTServerX/releases/releases/download/v1.3.0/IoTServer-1.3.0-windows-x64-setup.exe)
- [Portable ZIP](https://github.com/IoTServerX/releases/releases/download/v1.3.0/IoTServer-1.3.0-windows-x64-portable.zip)
- [Release notes, checksums and dependency notices](https://github.com/IoTServerX/releases/releases/tag/v1.3.0)

Install, open **IoTServer** from the Start Menu, configure your project, then **Apply Project** and **Start Runtime**. Use **Stop IoTServer** before upgrading.

[Visit the website](https://iotserverx.com/)
