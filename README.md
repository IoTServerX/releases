# IoT Server

Agentic industrial infrastructure for Windows. Connect equipment, organize signals,
and build visual maps with Lua, simulation and AI-assisted engineering.

## Download

- [Windows installer](https://github.com/IoTServerX/releases/releases/download/v1.3.0/IoTServer-1.3.0-windows-x64-setup.exe)
- [Portable ZIP](https://github.com/IoTServerX/releases/releases/download/v1.3.0/IoTServer-1.3.0-windows-x64-portable.zip)
- [Release notes, checksums and dependency notices](https://github.com/IoTServerX/releases/releases/latest)

Setup offers **Desktop** or **Windows service** mode, both installed in
`C:\Program Files\IoTServer`. The IS desktop shortcut opens the web UI at
[localhost:5180](http://localhost:5180). In Desktop mode, start the host using
**Start IoTServer** in the Start Menu. Service mode starts the host with Windows.

Configure your project, then **Apply** and **Start** the runtime. Stop the host
before upgrading; closing the browser does not stop it. Back up your project
and security stores first.

Without a full license, the runtime is limited to a four-hour process trial.
Use **Administration > Licensing** to obtain the machine ID and activate a license.

Windows binaries are unsigned. Drivers implement documented subsets; hardware
qualification and protocol certification remain incomplete.
